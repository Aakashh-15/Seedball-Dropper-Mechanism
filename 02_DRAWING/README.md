# 02_DRAWING — Seedball Dispenser Module

Engineering drawings for the Kriti26 drone-deployed seedball dispensing mechanism. Each component has two formats — a PDF for viewing and a DXF for use in CAD or drafting tools.

---

## File Structure

```
02_DRAWING/
├── 01_HOPPER.pdf / .dxf                — Hopper body drawing
├── 02_HOPPER_WITH-MOUNTS.pdf / .dxf    — Hopper with servo mounts drawing
├── 03_STORAGE.pdf / .dxf               — Storage module drawing
├── 04_V-FILE.pdf / .dxf                — V-File channel drawing
└── 05_CONNECTION.pdf / .dxf            — Connection bracket drawing
```

---

## Drawing Functions

- **Hopper** — Dimensional drawing of the base hopper body with wall angles, radii, and key reference dimensions.
- **Hopper with Mounts** — Hopper drawing with additional servo mounting hole positions and bracket tab dimensions.
- **Storage Module** — Dimensional drawing of the seedball reservoir including outlet width and mounting hole locations.
- **V-File Channel** — Drawing of the dual V-shaped dispensing channel with channel angle, length, and wall height.
- **Connection Bracket** — Dimensional drawing of the drone mounting bracket with radii and tab geometry.

---

## File Formats

| Format | Extension | Use Case |
|--------|-----------|----------|
| PDF | `.pdf` | Viewing, printing, and sharing drawings |
| DXF | `.dxf` | Importing into CAD or drafting tools (AutoCAD, FreeCAD, Fusion 360) |
